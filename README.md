# StudyBuddy AI (Notes Learning Buddy)

A full-stack, RAG-based study assistant that lets you upload your own notes and research papers, then ask questions in plain English — with every answer citing exactly which document and section it came from.

## Why this project

Built to turn scattered notes and papers into something you can actually ask questions of, instead of re-reading everything before an exam.

## Tech Stack

- **Backend:** FastAPI (Python)
- **Database:** SQLite (via SQLAlchemy ORM)
- **Embeddings:** sentence-transformers (local, no API cost)
- **Vector Store:** ChromaDB
- **LLM:** Ollama (local — Llama 3.2 / Phi-3)
- **Frontend:** HTML, CSS, JavaScript
